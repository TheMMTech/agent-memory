# Getting help

Agent memory is maintained by one person in their spare time. There is no
service-level agreement.

1. Start with the [documentation index](docs/memory/guides/README.md),
   especially [Troubleshooting](docs/memory/guides/troubleshooting.md).
2. Run `python tools/memory/memory.py check --json` in the affected repository
   and read what it reports.
3. Search [existing issues](https://github.com/TheMMTech/agent-memory/issues).
4. If it still looks wrong, open a bug report or feature request using the issue
   forms. Use synthetic data only.

Security problems are never reported in issues: see [SECURITY.md](SECURITY.md).
Contributions are welcome: see [CONTRIBUTING.md](CONTRIBUTING.md).
